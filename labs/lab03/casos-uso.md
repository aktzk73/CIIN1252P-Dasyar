# Casos de uso
## 1. Casos de uso identificados
- CU01: Autenticar Administrador
- CU02: Registrar Marcación
- CU03: Gestionar Trabajadores
- CU04: Gestionar turnos y tolerancias
- CU05: Generar reportes
- CU06: Corregir Asistencias
- CU07: Exportar Asistencias Excel
- CU08: Cambiar Contraseña
- CU09: Calcular faltas y horas extras

## 2. Relaciones
CU07 «extend» CU05: se extiende solo si el administrador decide exportar a Excel el reporte generado.
