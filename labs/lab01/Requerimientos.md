# Lab01: Requerimientos Funcionales y No Funcionales
| ID | Tipo | Descripción |
| - | - | - |
| RF-01 | Funcional | El sistema debe permitir registrar a un trabajador con los parametros nombre y DNI.|
| RF-02 | Funcional | El sistema debe permitir registrar la hora de entrada y salida de un trabajador. |
| RF-03 | Funcional | El sistema debe permitir generar reportes de asistencia.|
| RF-04 | Funcional | El sistema debe permitir autenticar al administrador.|
| RF-05 | Funcional | El sistema debe permitir configurar turnos y una tolerancia.|
| RF-06 | Funcional | El sistema debe permitir corregir la asistencia indicando un motivo. |
| RF-07 | Funcional | El sistema debe permitir al administrador cambiar su contraseña. |
| RF-08 | Funcional | El sistema debe calcular las faltas y horas extras de cada trabajador |
| RNF-01 | No Funcional | Seguridad: El sistema debe garantizar la seguridad y protección de los datos sensibles de los trabajadores |  
| RNF-02 | No Funcional | Usabilidad:  El sistema debe asegurar que el proceso de registro de asistencia de los trabajadores sea menos de 1 minuto, sin capacitacion previa en al menos el 95% de los casos |
| RNF-03 | No Funcional | Rendimiento: Las página principales del sistema deben cargar en un tiempo máximo de 5 segundos bajo condiciones estables de conexión a internet(10 Mbps o superior)|
